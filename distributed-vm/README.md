# Distributed VM

## Prerequisites

- `protoc` from an [official release](https://github.com/protocolbuffers/protobuf/releases) (21.x),
  with its `include/` directory: the Ubuntu `protobuf-compiler` package omits the `google/protobuf`
  includes the build needs. See [`docs/how-to-setup-gpu-machine.md`](../docs/how-to-setup-gpu-machine.md).
